# Providers

The provider control plane supports OpenAI, Anthropic, OpenRouter, Gemini, Vertex AI, Bedrock, Azure OpenAI, Databricks AI Gateway, Snowflake Cortex, Mistral, Groq, DeepInfra, Cerebras, Cohere, Together, Perplexity, xAI, LM Studio, Ollama, Vercel AI Gateway, NVIDIA and authorized GitHub Copilot configuration.

Adapters normalize messages, tools, usage/cache/reasoning tokens and errors. Mock transports make request mapping testable without external credentials.
