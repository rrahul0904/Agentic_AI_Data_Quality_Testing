## Security follow-up

A local runtime environment search accidentally emitted a credential into an internal tool result during the payments audit. The value is intentionally not repeated here. Treat that credential as exposed and rotate/revoke it through the owning provider, then update the local secret store. No rotation was performed as part of this read-only Phase 2 work; access to those local secrets should be restricted and future diagnostics must avoid printing `.env` contents.
